# Тихие Стены — интерактивный каталог

Локальный сайт на React, TypeScript, Vite и Tailwind CSS. Книга построена на Three.js; StPageFlip используется как резервный режим. Отдельный сервер приложения и учетная запись не требуются. В каталоге используются реальные фотографии из предоставленной папки; демонстрационные ткани не добавлены.

## Запуск

Требуется Node.js 22.13 или новее.

```sh
npm install
npm run dev
```

Откройте адрес, который напечатает Vite. Для завершения сервера нажмите `Ctrl+C`.

```sh
npm run typecheck
npm run lint
npm test
npm run build
npm run preview
```

## Управление книгой

- Нажмите на обложку или стрелку справа, чтобы открыть каталог.
- Потяните угол листа, нажмите стрелку или проведите пальцем по странице.
- Клавиши `←` и `→` перелистывают книгу; `Home` возвращает к обложке. Клавиши не перехватываются в диалогах и полях ввода.
- «Содержание» открывает поиск и переход к ткани.
- Кнопка `+` на подписи ткани открывает ее оригинал. Масштаб меняется кнопками; увеличенное изображение можно перетаскивать мышью или прокручивать на телефоне.
- Кнопка развертывания включает полный экран; если браузер не поддерживает Fullscreen API, используется режим без шапки. `Esc` выходит из этого режима.
- Настройка системы «Уменьшение движения» отключает продолжительные анимации.

## Трехмерная книга

Для основного режима требуется WebGL 2. При недоступности или потере графического контекста сайт автоматически переходит к StPageFlip, сохраняя текущую страницу. Кнопка «Повторить 3D» позволяет вернуться к объемной книге.

Обложки и листы имеют геометрию с толщиной. Жесткая обложка поворачивается целиком, тканевый лист изгибается по сетке с неизменными UV-координатами. Крепежные отверстия перемещаются вдоль четырех металлических колец. При коротком перетаскивании лист возвращается, при достаточном перемещении или быстром жесте перелистывание завершается. Переход к далекому образцу выполняется одним переворотом пачки листов.

На компьютере показан разворот, на узком экране — одна страница. Масштаб камеры рассчитывается из доступной ширины и высоты. Уменьшенные плашки расположены у внешних нижних углов; длинные названия ограничены двумя строками с полным текстом в подсказке. Область нажатия «+» составляет 44 × 44 CSS px до проекции в сцену.

Фактуры рисуются без цветового тонирования; затенение находится в отдельном слое. Пропорции изображения сохраняются. Оригиналы не передаются в GPU: сцена использует версии для каталога и ограниченный кеш до восьми текстур размером не более 1024 × 1024. Геометрия не создается для всех 103 образцов одновременно. В покое непрерывный цикл отрисовки остановлен; при скрытой вкладке кадры не запрашиваются. Текстуры, геометрии, обработчики и графический контекст освобождаются при закрытии сцены.

## Импорт через интерфейс

Кнопка с двумя ползунками внизу справа открывает управление каталогом. Все изменения сначала попадают в черновик. Нажмите «Сохранить», чтобы применить их и записать в IndexedDB этого браузера. При нехватке места появится ошибка; текущий каталог не будет заменен.

**Это локальные данные конкретного браузера и адреса сайта.** Они не отправляются на сервер, не становятся доступны другим посетителям и могут быть удалены при очистке данных браузера. Используйте импорт через папку проекта для постоянного общего каталога на хостинге.

### Изображения

Поддерживаются JPG, JPEG, PNG и WebP до 60 МБ на файл. Выберите «Добавить к текущим» или «Заменить каталог». Имена файлов станут предварительными названиями. Названия и артикулы можно исправить в списке; стрелки меняют порядок. При активном поиске перестановка отключена, чтобы не менять скрытые позиции случайно.

Оригинал сохраняется отдельно от облегченной версии страницы. Изображения обрабатываются последовательно. Большой импорт может занять время и потребовать свободного места в браузере.

### PDF

Поддерживаются PDF до 60 МБ и 200 страниц. Каждая страница переносится **целиком** в книгу с сохранением порядка и пропорций. Название вида «имя файла · номер страницы» — предварительное: оно не считается распознанным названием ткани. Если одна PDF-страница содержит несколько образцов, загрузите отдельные изображения для каталога «одна ткань — одна страница». PDF с паролем необходимо предварительно разблокировать самостоятельно.

### Excel

Поддерживается `.xlsx`, первый лист, первая строка — заголовки. До 10 МБ и 10 000 строк. Формат `.xls` предварительно сохраните как `.xlsx`.

| Название | Артикул | Файл |
| --- | --- | --- |
| Фактическое название из вашей таблицы | Фактический артикул | Точное имя изображения.jpg |

Столбец «Название» обязателен. Также распознаются `Name`, `Title`, `Fabric`; для артикула — `SKU`, `Article`, `ID`, «Код»; для файла — `File`, `Filename`, `Image`, «Имя файла», «Изображение».

Сначала проверяются точное имя файла и точное предварительное название, затем артикул как самостоятельный идентификатор. При нескольких совпадениях, отсутствии совпадений или конфликтующих строках пользователь выбирает ткань вручную либо пропускает строку. Одна ткань не может получить несколько названий из разных строк. После подтверждения используется порядок сопоставленных строк Excel; остальные материалы остаются после них в прежнем порядке. Ведущие нули в артикулах нужно хранить в Excel как текст.

### Обложка, логотип и контакты

В соответствующих вкладках загрузите фото обложки и логотип (JPG/PNG/WebP, до 30 МБ), укажите контакты. Для логотипа рекомендуется белое изображение на прозрачном фоне. Для обложки — квадратная фронтальная фотография.

**Фото оригинальной обложки, логотип и видео не были предоставлены.** Текущая обложка — временный графический макет; надпись в шапке — текстовая замена логотипа. Их нельзя считать точной копией оригинала. Один и тот же рисунок используется в 3D-книге и резервном режиме. После получения видео нужно сверить расположение креплений и направление перелистывания с физической книгой.

Контактные поля изначально пусты. Телефон, почта и адрес не выдумываются.

## Подключение через папку проекта

```text
public/
  images/
    logo/                 # оригинальный логотип
    cover/                # фото обложки
    fabrics/              # оптимизированные WebP и миниатюры
  catalog/
    originals/            # неизмененные оригиналы фотографий
    settings.json         # пути обложки/логотипа и контакты
src/
  components/
    Header.tsx
    CatalogBook.tsx
    Book3D.tsx
    FlatCatalogBook.tsx
    BookCover.tsx
    FabricPage.tsx
    CatalogManager.tsx
  data/fabrics.json        # формируется автоматически
  book3d/                  # геометрия, модель страниц, текстуры и сцена
  App.tsx
scripts/import-catalog.mjs
```

Поместите новые исходные изображения в отдельную папку и выполните:

```sh
npm run import:catalog -- "/абсолютный/путь/к/фотографиям"
npm run build
```

Команда сформирует список тканей, WebP до 1400 px, маленькие миниатюры и копии оригиналов без изменения исходной папки. Структура описания тканей остается в `src/data/fabrics.json`; ручной код для каждой ткани не нужен. При повторном импорте ранее сформированные неиспользуемые файлы автоматически не удаляются.

По умолчанию используется сортировка имен с учетом чисел, а не подтвержденный порядок физической книги. Для точного порядка добавьте в исходную папку `order.json` — массив имен файлов:

```json
["точное имя первого файла.jpg", "точное имя второго файла.jpg"]
```

Файлы, не перечисленные в `order.json`, добавляются в конце. Некорректные и повторяющиеся имена приводят к ошибке импорта.

Чтобы заменить обложку или контакты без изменения исходного кода, положите файлы в `public/images/cover/` и `public/images/logo/`, затем заполните `public/catalog/settings.json`:

```json
{
  "cover": "/images/cover/cover.jpg",
  "logo": "/images/logo/logo.png",
  "contacts": { "phone": "", "email": "", "address": "" }
}
```

Если в браузере уже сохранен собственный каталог, он имеет приоритет над настройками папки проекта. Для проверки чистой сборки используйте другой профиль браузера либо очистите данные сайта.

## Размещение

После `npm run build` папка `dist` готова для обычного статического хостинга в корне домена. Маршрутизация на сервере не нужна. Исходные изображения занимают около 525 МБ, поэтому для хостинга потребуется соответствующее место. Они загружаются только при увеличении, а не при открытии сайта. В книге подгружаются текущие и соседние страницы; PDF.js, обработчик Excel и редактор импортируются отдельными модулями по запросу.

Публикация, коммиты и отправка в Git в ходе локальной разработки не выполняются автоматически.
